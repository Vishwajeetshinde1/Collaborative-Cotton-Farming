03 / PORTABILITY

Export & import records

Export farmers, lots, bale IDs, quality parameters, metrics and QR settings as a JSON backup. Use it to transfer this prototype dataset to another browser.

Backup before every import.Import replaces the current browser dataset. Keep the downloaded JSON in a secure location because it may contain private farmer contact details.
